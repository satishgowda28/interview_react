# Claude Code Guidelines

## Project Purpose
This is a React practice/learning project. The goal is to analyze the user's React coding skills and suggest improvements.

## Analysis Rules
- **Only analyze folders/files explicitly requested by the user.** Do not read or explore the entire project.
- Focus feedback on React-specific patterns, best practices, and skill improvement.
- When analyzing code, highlight both strengths and areas for improvement.

## Feedback Style
- Be specific — reference file paths and line numbers.
- Prioritize React fundamentals: component design, hooks usage, state management, performance.
- Suggest improvements without rewriting everything — aim to teach, not just fix.

## Suggestions Output
- After analyzing a folder, always save the suggestions to a `suggestion.md` file inside that folder (e.g., `src/pages/nestedcheckbox/suggestion.md`).
- The file should include both strengths and issues, with file references and code examples.
